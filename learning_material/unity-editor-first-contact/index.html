01 · SETUP

Install Unity and identify its two applications

Unity uses two desktop applications with separate responsibilities. Instructions that say “open Unity” may refer to either application.

UNITY HUB

Installation and project manager. It installs Editor versions, manages licenses, and creates or opens projects.

UNITY EDITOR

Authoring application. It edits scenes and GameObjects, runs Play mode, and builds executables.

Unity Personal is the normal free starting plan for individuals. Eligible students can also enroll in the Unity Student plan for education-focused benefits. Plan terms can change, so use Unity’s current page as the source of truth.

  1. Download and install Unity Hub, then sign in with your Unity account.
  2. In the Hub, open Installs and choose Install Editor.
  3. Select the Unity 6 version used in class. If asked, choose the module for a compatible code editor.
  4. Wait for the installation to finish. The Editor is large, so this can take time.
Installation verification Confirm that Unity Hub opens, your account is signed in, and a Unity 6 Editor appears under Installs.

02 · PROJECT

Open the Unity Essentials project

The course uses Unity’s Essentials Pathway template. It already contains the robot, playground, scenes, shortcuts, and mural pieces used in this lecture.

  1. Open Unity Hub and select New project.
  2. At the top, choose Unity 6.0 or newer.
  3. Select the Essentials Pathway template.
  4. Name the project, choose a safe location, and select Create project.
Use one instruction source at a time. Both the website and embedded tutorial modify the same project. Use a second display if one is available.

If you follow this article or the Unity Learn website, switch the top-right Layout menu to Default. You can restore Unity’s tutorial panel later through Tutorials → Show Tutorials.

03 · INTERFACE

Understand the Editor window model

The Default layout displays multiple windows simultaneously. Each window exposes a different scope of project data or a different view of the active scene.

AreaData scopePrimary function
ProjectFiles and reusable assets stored in the projectAccess reusable source assets.
HierarchyGameObjects instantiated in the active sceneAccess the current scene graph.
SceneEditable spatial view of the scenePosition and inspect GameObjects.
GameOutput from the active CameraPreview camera output during Play mode.
InspectorComponents and serialized values on the selectionInspect and modify object data.
Data scope The Project window lists assets stored on disk. The Hierarchy lists instantiated GameObjects in the active scene.
Open the starter scene In the Project window, open Assets → _Unity Essentials → Scenes, then double-click -1_Starter_Scene. The robot and its environment should appear.

Hierarchy means parent and child

GameObjects can be organized as a tree. A parent contains child GameObjects. Expand the triangle beside Boxes in the Hierarchy to see this structure.

Double-clicking any GameObject in the Hierarchy frames it in the Scene view. If you get lost, double-click Ground to return to a wide view of the environment.

04 · OBJECTS + PLAY

Modify GameObjects and verify behavior in Play mode

SCENE VIEW · AUTHORING VIEWPORT

Manipulate scene contents from an editor-controlled camera.

GAME VIEW · CAMERA OUTPUT

Display the output of the active Camera during Play mode.

Select the Play button at the top center of the Editor. Unity enters Play mode and shows the Game view. In the starter scene, use the arrow keys or WASD to move, Space to jump, the mouse to look, and Shift to run.

Play mode state is temporary Changes made while Play mode is active are normally discarded when Play mode stops. Exit Play mode before making changes that must persist.

Inspect components and Transform data

Select a GameObject in the Scene or Hierarchy. Its components appear in the Inspector. Components provide properties and behavior: the Transform stores position, rotation, and scale; other components can make the object visible, interactive, physical, or scripted.

X · red · left/right Y · green · up/down Z · blue · forward/back
Transform exercise
  1. Exit Play mode and select the Star GameObject.
  2. Find Position at the top of the Inspector.
  3. Reduce X by 1–2 units and Y by 1–2 units.
  4. Enter Play mode and try to collect the star. Stop when finished.
If you make a mistake, use Ctrl/Cmd + Z.

Persist changes by saving the scene

Unity does not automatically save your scene. An asterisk beside the scene name means there are unsaved changes. Press Ctrl/Cmd + S; the asterisk should disappear.

05 · 3D NAVIGATION

Use the Scene view navigation controls

Navigation is a prerequisite for object placement: first control the Scene camera, then edit the scene. Unity Learn compares this to learning how to hold a pencil before drawing.

Open _Unity Essentials → Scenes → 1_Playground_Navigation_Scene. Move slowly at first. Tap a key, observe the result, and reset your view often. Speed comes after control.

ActionControlEffect
FrameF or double-click a GameObjectCenter and scale the view around the selection.
LookRight-click + dragRotate the Scene camera in place.
FlyHold right-click + WASD; Q/E down/upTranslate and rotate the Scene camera concurrently.
OrbitAlt/Option + left-dragRotate the Scene camera around the selected pivot.
ZoomMouse wheel or two-finger trackpad scrollMove the Scene camera toward or away from the pivot.
PanSelect the Hand/View tool, then left-dragTranslate the Scene camera parallel to the view plane.

The top-row tool shortcuts form a memorable sequence: Q View, W Move, E Rotate, R Scale, T Rect, and Y Transform.

Perspective vs Isometric

The Scene gizmo is the cube and colored cones in the upper-right of the Scene view. Click a cone to align to a side or top view. Right-click the gizmo and disable Perspective to enter Isometric mode. Isometric view removes perspective distortion, which can reveal shapes hidden by depth.

07 · OBJECT MANIPULATION

Design a mural in Scene view

The mural exercise applies Move, Rotate, coordinate-space, and projection controls to tangram pieces. Use the supplied reference or define another valid arrangement.

Global and Local coordinates

GLOBAL

The axes stay fixed like north, south, east, and west. This is useful when every piece should move in the same world directions.

LOCAL

The axes rotate with the object—its own forward, up, and side. This is useful when movement should follow the object’s orientation.

Move across X · red Move across Z · blue Rotate around Y · green
  1. Select the Mural GameObject, enable it in the Inspector, and double-click it to frame the pieces and reference.
  2. Use the Scene gizmo for a top view. Choose Global coordinates.
  3. Press W for Move. Start with a large triangle and position it using the red X and blue Z arrows.
  4. Press E for Rotate. Drag the green Y ring with a straight mouse motion until the piece fits.
  5. In Isometric view, drag the small square between the X and Z arrows to slide a piece across both axes at once.
  6. Complete the design, disable Tangram_Reference, restore Perspective, orbit to inspect the result, and save.
Efficient workflow Position first. Rotate second. Switch between W and E. Save after every meaningful improvement.
